# Segmented

GlassSegmented picks one of two to four options that change the whole form below it, such as expense, income or transfer.

Its track is `color-surface` with a `color-hairline` border and `radius-lg`; the picked option is `color-surface-selected` with `color-text` and `radius-md`, the others `color-text-subtle`. It is 52 px high and as wide as its column. The consumer provides the options and the one picked. For a short row of periods or filters use chips instead.
