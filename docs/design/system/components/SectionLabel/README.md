# SectionLabel

SectionLabel names a group of rows in short spaced capitals: `text-label` in `color-text-muted`, such as ACCOUNTS or LIMITS FOR NOVEMBER.

BirkaRule is the hairline between parts of a card: 1 px of `color-hairline`. BirkaLinkRow is a row in `color-accent` with a chevron that opens the whole of what a card shows in part, at least `size-touch-target` high. The consumer provides the text, and the `href` for a link row.
