# ChangePill

BirkaChangePill says how a figure moved against the period before: the change of the capital, of a category in reports.

Good news (`birka-change-pill--rise`) is `color-positive` on its 16 % tint, bad news (`birka-change-pill--fall`) `color-negative` on its tint, each with an arrow, so the color is never alone. Which way is good is the consumer's call: spending that falls is good news. The consumer provides the text and whether it is good.
