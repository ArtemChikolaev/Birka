# GlyphBadge

GlyphBadge shows a category: its icon in its color on a 16 % tint of that color, `radius-sm`, 36 px by default.

The colors are the seven of the categories: `color-palette-green`, `amber`, `sky`, `violet`, `rose`, `orange`, `cyan`. A category without a color uses `color-text-subtle`. The consumer provides the glyph, the color as CSS and the size. A badge stands beside the name of what it shows; it never replaces the name.
