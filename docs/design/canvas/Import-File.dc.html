Как это устроено

  1. 1Узнаём банк по колонкам файла: Альфа-Банк, Т-Банк, Дзен-мани, Wise, Revolut или ваш формат
  2. 2Показываем каждую строку так, как она попадёт в учёт
  3. 3Не задваиваем то, что вы уже записали вручную
  4. 4Импорт отменяется целиком, одной кнопкой, хоть через месяц
