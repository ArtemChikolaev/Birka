Перенос через файл

  1. На устройстве с записями откройте «Ещё» → «Данные» и сохраните копию.
  2. Передайте файл на новое устройство.
  3. Откройте там «Данные» → «Восстановить из копии». Проверьте сводку и подтвердите замену записей.
Учёт доступен на этом устройстве и без входа.
